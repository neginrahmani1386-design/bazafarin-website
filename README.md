# Bazafarin Website

The official website for **Bazafarin**, an Iranian startup that makes anti-gravity treadmills for rehabilitation and physical therapy.

🌐 **Live site:** [bazafarinidea.com](https://bazafarinidea.com/)

## About
I designed and built this website to introduce Bazafarin's anti-gravity treadmill, explain how it supports recovery, and help clinics and patients get in touch.

## Features
- Persian-language content for an Iranian audience
- A library of anonymized clinical case studies (PDF) covering orthopedic, neurological and cardiac rehabilitation
- Contact form and embedded map
- Accessible colour system with checked text contrast
- Set up with Google Search Console for search visibility

## Built with
- HTML, CSS and JavaScript
- Developed with AI-assisted coding in Cursor
