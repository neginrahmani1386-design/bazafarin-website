# وب‌سایت باز آفرین ایده — تردمیل کاهندهٔ وزن جی کاه (GK)

وب‌سایت معرفی محصول، ساکن (static) و کاملاً فارسی/راست‌به‌چپ (RTL). بدون نیاز به بک‌اند،
دیتابیس یا مرحلهٔ build — فقط فایل‌های HTML/CSS/JS و تصاویر.

---

## ۱. ساختار فایل‌ها

```
site/
├── index.html          # خانه (هیرو، معرفی، مزیت‌ها، مخاطبان، نصب‌ها، CTA)
├── product.html        # دستگاه و مشخصات فنی + اجزا + گالری
├── who-needs.html      # چه کسانی نیاز دارند؟ (+ بخش B2B و دیسکلیمرها)
├── about.html          # دربارهٔ ما، ثبت اختراع، تایم‌لاین سه نسل، نصب‌ها
├── contact.html        # نشانی، تلفن‌ها، فرم مشاوره، محل نقشه
├── css/
│   └── styles.css      # تمام استایل‌ها (RTL، پالت رنگ، ریسپانسیو)
├── js/
│   └── main.js         # منوی موبایل، اسکرول‌ریویل، سال فوتر، اعتبارسنجی فرم
├── assets/
│   ├── logos/          # gk-logo-wide.png (هدر) · gk-logo-wide-transparent.png (فوتر)
│   ├── img/            # عکس‌های واقعی دستگاه و کارگاه
│   └── fonts/          # فونت Vazirmatn (۶ وزن، woff2) + OFL.txt (لایسنس)
└── README.md
```

## ۲. پیش‌نمایش محلی

چون سایت ساکن است، کافی است یک سرور ساده اجرا کنید (به‌خاطر بارگذاری صحیح فونت‌ها و تصاویر):

```bash
cd site
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

یا با Node:

```bash
npx serve site
```

باز کردن مستقیم فایل `index.html` هم کار می‌کند، اما اجرای سرور محلی توصیه می‌شود.

## ۳. سفارشی‌سازی

### رنگ‌ها و فونت
تمام رنگ‌ها به‌صورت متغیر CSS در ابتدای `css/styles.css` تعریف شده‌اند:

```css
:root {
  --blue-700: #167899;   /* متن روی پس‌زمینهٔ روشن */
  --blue-600: #1D8BBC;   /* پس‌زمینه‌ها، دکمه‌ها، تینت‌ها */
  --blue: #22A2DB;       /* هاور و حالت روشن‌تر */
  --charcoal: #283132;   /* رنگ تیرهٔ برند */
  ...
}
```

فونت **Vazirmatn** به‌صورت محلی در `assets/fonts/` قرار دارد (نیازی به اینترنت ندارد).

### جایگزینی عکس‌ها
عکس‌های داخل `assets/img/` را با فایل‌های جدید و **هم‌نام** جایگزین کنید تا بدون تغییر کد به‌روزرسانی شوند.
نسبت ابعاد پیشنهادی: هیرو و تصاویر بزرگ افقی، گالری ۴:۳.

### لوگو
- `assets/logos/gk-logo-wide.png` — لوگوی GK برای هدر روی پس‌زمینهٔ روشن
- `assets/logos/gk-logo-wide-transparent.png` — همان لوگو با پس‌زمینهٔ شفاف، برای فوتر روی `#1a1f20`
- `assets/logos/gk-logo.png` و `assets/logos/gk-logo-white.png` — نسخه‌های قدیمی؛ در سایت استفاده نمی‌شوند (پشتیبان)

### اطلاعات تماس (مهم)
مقادیر نمونه را با اطلاعات واقعی جایگزین کنید:

- **`contact.html`** — سه شمارهٔ تلفن (`href="tel:..."`) و ساعات کاری. کامنت `TODO` گذاشته شده.
- **فوتر همهٔ صفحات** — شمارهٔ تلفن در بخش فوتر (در هر ۵ فایل HTML تکرار شده).
- **نقشه** — در `contact.html` بخش «محل نقشه»؛ کد `iframe` گوگل‌مپ یا نشان را جایگزین placeholder کنید.

> نکته: شماره‌ها در `tel:` باید به شکل بین‌المللی و لاتین باشند، مثال: `tel:+982112345678`.

## ۴. اتصال فرم تماس

فرم صفحهٔ تماس در حال حاضر **فقط اعتبارسنجی سمت کاربر** دارد و پیام را ارسال نمی‌کند
(داده‌ها فقط در کنسول مرورگر لاگ می‌شوند). برای فعال‌سازی ارسال، یکی از دو راه:

**الف) سرویس فرم آماده (بدون کدنویسی بک‌اند):**
در `contact.html` ویژگی `action` فرم را به سرویس موردنظر وصل کنید:

```html
<form id="contact-form" action="https://formspree.io/f/XXXX" method="POST">
```

سرویس‌های رایج: Formspree، Getform، Web3Forms.

**ب) بک‌اند اختصاصی:**
در `js/main.js` جایی که کامنت `NOTE FOR DEVELOPER` هست، شیء `data` آمادهٔ ارسال است؛
با `fetch()` آن را به API خود بفرستید:

```js
fetch('/api/contact', { method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify(data) })
```

اعتبارسنجی موبایل ایرانی (`09xxxxxxxxx` یا `+989xxxxxxxxx`) از پیش در `main.js` تنظیم شده است.

## ۵. انتشار (Deploy)

سایت ساکن است و روی هر هاست استاتیکی کار می‌کند. چند گزینهٔ رایگان و آسان:

### Netlify (کشیدن‌ورهاکردن)
۱. وارد [netlify.com](https://netlify.com) شوید.
۲. پوشهٔ `site/` را در بخش «Deploys» رها (drag & drop) کنید.
۳. آدرس آمادهٔ سایت را دریافت می‌کنید. برای دامنهٔ اختصاصی، از بخش Domain settings استفاده کنید.

### Vercel
```bash
npm i -g vercel
cd site
vercel
```

### GitHub Pages
۱. محتوای `site/` را در یک ریپازیتوری گیت‌هاب قرار دهید.
۲. در **Settings → Pages**، منبع را روی شاخهٔ `main` و پوشهٔ ریشه (`/root`) تنظیم کنید.
۳. سایت روی `https://<username>.github.io/<repo>/` منتشر می‌شود.

### هاست معمولی (cPanel / FTP)
تمام محتویات پوشهٔ `site/` را در `public_html` (یا ریشهٔ وب) آپلود کنید. همین.

## ۶. نکات فنی

- **ریسپانسیو:** موبایل، تبلت و دسکتاپ پشتیبانی می‌شود؛ منوی موبایل به‌صورت همبرگری.
- **RTL:** کل سایت با `dir="rtl"` و `lang="fa"` و چیدمان راست‌به‌چپ طراحی شده.
- **بدون وابستگی خارجی:** فونت محلی است و هیچ CDN یا کتابخانهٔ بیرونی بارگذاری نمی‌شود.
- **دسترس‌پذیری:** متن جایگزین (alt) برای تصاویر، برچسب برای فیلدهای فرم، و `aria-*` روی منو.
- **سئو:** هر صفحه `title` و `meta description` اختصاصی دارد.

## ۷. یادداشت دربارهٔ محتوا

- ادعاهای پزشکی به‌صورت محتاطانه («می‌تواند کمک کند») بیان شده و در صفحهٔ «چه کسانی نیاز دارند؟»
  و مثال آموزشی، تأکید بر **نظارت پزشک/متخصص** آمده است.
- فناوری دستگاه به‌عنوان طراحی مستقل و بومی و **دارای ثبت اختراع** معرفی شده (بدون ذکر شمارهٔ اختراع؛
  در صورت تمایل، شمارهٔ واقعی را اضافه کنید).
- شمارهٔ تلفن، ساعات کاری و نقشه به‌صورت **نمونه** هستند و باید پیش از انتشار جایگزین شوند.
